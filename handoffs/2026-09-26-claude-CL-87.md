## The model packages' review (after the others)

A fifth reviewer read the model packages (models as data, the model lab and sheets): two mediums and
nine lows. Fixed, each with a test that fails on the code before it:
- Medium: the game didn't start if any model file had a syntax error (rigs.js imported them statically
  at boot). The model rigs now load behind a guard: a broken file is a console warning.
- Medium: every spider adopt rebuilt the whole model (3.4 ms). A rig builds once and copies.
- `instanceModel` gives a copy its own limbs and meshes; `validateModel` says a null body piece, a body
  with no frame, a mirrored chain on joints with no twins, `"toString"` as a material and an owner
  outside the crew; `planVersion` won't draw an older file under a newer label; `render-sheet` refuses
  links; `check-model-lab` needs the real write door to save.
- The lab launchers' port check matched the browser's own connection and could `taskkill` the
  browser; fixed in both lab .bat files (not tried on Windows); `Play Dead-Wave.bat` asked of Cursor.
- A spider timing claim in the draft didn't reproduce; the docs say what can be said.
