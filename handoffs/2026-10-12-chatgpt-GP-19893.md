## Implementation and limits

- Fence is three batched meshes and two ballistic/camera edge solids. Diamond wire uses geometry rather than an alpha texture. No extra lights or per-zombie render effects.
- Full bay swept collision prevents sprint/roll tunnelling and permits tangent sliding. Zombies track their last position and cannot use the bay while raised. Down only during the existing post-purge recovery/exit period; reset/leave/reentry cannot duplicate solids or leave the fence open.
- Only medical furniture is tagged as a prop. Medical floor/backdrop wall panels retain the existing architectural cutaway. Existing GB-163 fade hysteresis, GP-19883 stable shader pipeline, GP-19892 station reach/security and hazard cleanup are preserved.
- First live collision probe exposed an ejection bug toward the rear wall; fixed by allowing the enclosure to eject only toward its two open edges, with a regression test. A prompt probe initially sampled the ordinary CSS fade before it settled; the final probe waits for the settled visible state and asserts full opacity.
- Fresh UTF-8 reads and hash guards were used for source saves. Concurrent Claude CL-187 zombie-feet changes remain intact; no snapshot restoration, reformatting, git or GitHub operations.
