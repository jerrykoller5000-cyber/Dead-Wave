## How
handoffs/2026-10-09-grokbot-GB-155/rename.cjs makes one read-modify-write per file. It reads the bytes, skips the file
unless they round-trip as UTF-8 (no re-encoding, BOMs and line endings kept), masks the protected identifiers, makes
exact string swaps, checks the expected count, re-reads the file and writes only if it's byte-identical to the first
read. Result: 159 replacements in 92 files, 0 problems. inv.cjs is the inventory script (case-insensitive
dead[ _-]?wave). The before and after inventories are in the folder (inventory-before.txt, 1051 lines including build
output and history; inventory-after.txt).
