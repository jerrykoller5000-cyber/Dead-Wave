# GB-127 - Full auto by default (Jerry, final say)

Agent: Grokbot. Date: 2026-10-02 (CT).

## Changed
- Every gun that can fire full auto now starts on AUTO: new run, buy, swap, reload, holster/draw, and the
  pistol as soon as its auto sear is fitted. Guns with no auto (shotgun, revolver, sniper, launcher) are
  unchanged. The Uzi, minigun, flamethrower and chainsaw were always auto.
- New const FIRE_MODE_DEFAULT = 'auto'. fireMode init, resetFireModes() and the weaponIsAuto() fallbacks use it.
- The pistol's mode is no longer forced to 'semi' when the sear is unfitted at the Armory. Unfitted, it fires
  semi whatever fireMode says (weaponIsAuto checks pistolAutoFitted). Fitted again, it goes back to his last
  choice, which is AUTO by default.
- Player choice: a K press is kept for that gun for the rest of the run (through swaps, reloads, holster).
  Only a new run (resetEconomy -> resetFireModes) puts every gun back on AUTO. Nothing was ever persisted
  to localStorage, and that's still true.
- HUD: #ammoDetail reads AUTO from the start, because updateAmmoHud reads weaponIsAuto. No HUD code changed.
- This overrides D-65 / P-128 ("start on semi"). Jerry's call.
