How:
- The shirt, trousers and helmet cover share one 256 px camo canvas. A swap repaints that canvas and flags the texture, so it costs no material, draw call or memory, and the marine changes in the same frame.
- M81 US Woodland is the tile the marine was built with (Jerry: "marine is wearing woodland"). It is the default and is copied at boot, so going back to it restores the original tile pixel for pixel (t102 checks this).
- The other 14 are painted by `core/camo.js` from wrapping value noise (seamless), with digital blocks for UCP, MCCUU, MARPAT and CADPAT, and dabs for Flecktarn, Multicam and DBDU's chocolate chips. Deterministic: its own LCG, not Math.random or the world seed.
- The panel pauses the game like the kiosk but is see-through and sits to the right, so the marine can be seen changing. No price anywhere: each button says "Free" or "Wearing".
- Stored under localStorage `tt_camo`. A new run keeps the pattern; it is cosmetic, so it is not part of the run save.
