## Proposed consumer API

- HIKERS: frozen identity/age/local portrait URL records.
- hikerById(id): localized name and line plus the record; null for an unknown id.
- loadHikerPortraits(ImageCtor = Image): Promise<Map<id, image>>, shared by concurrent callers. A failed load names the identity and permits an explicit retry.
- drawHikerPortrait(ctx, id, rect, portraits): contain-fitted portrait in {x,y,w,h}.
- drawHikerPoster(ctx, id, rect, portraits): complete poster at any final canvas size; natural aspect 384:512.
- drawHikerRoster(ctx, rect, portraits): six posters and heading; natural aspect 1152:1120.
- paintHikerPosters(posters): awaits images, repaints AG-125 userData.canvas using userData.hiker.id, flags the existing userData.tex for upload, returns the painted count.

The concrete import/call examples are in integration.md. The painter keeps the owner's existing canvas dimensions. Enlarging an already uploaded canvas from 192×256 to 384×512 left the old WebGPU texture visible in the first preview. That defect is fixed: preview-v3 records all six existing canvas/texture identities preserved, dimensions 192×256, texture/source versions incremented to 2, and the screenshots show all six faces.
