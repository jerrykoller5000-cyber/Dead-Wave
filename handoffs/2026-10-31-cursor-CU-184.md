## The changes behind it, and their owners

1. **`sceneCull` (CL-277, Claude; index.html, the unit list at the start of `sceneCull`).** 1.0 walked `scene.children` directly. CL-277 builds `_cullUnits` every frame: `kids.length = 0`, then `kids.push` for every scene child and, for a group marked `cullKids` (the 287 history props), each of its children (`fn-diff.mjs sceneCull`: the diff is those six lines; `cullSkipSet`, `cullLiveSet`, `cullHide` and `cullShow` are identical to 1.0). Setting `length = 0` on a long array lets V8 drop its backing store, so each frame it regrows by pushing a few hundred items: about 20 kB a frame, which is the 21.4 kB. Untried fix for the owner: keep the array and a count (`n = 0`, write `kids[n++] = k`, loop to `n`), or rebuild the list only when the scene's child count changes.
2. **`objectives.snapshot()` (game/objectives.js, GP-11, ChatGPT's; the callers are in index.html and its UI).** Unchanged since September; each call clones every site (`[...sites.values()].map(site => ({ ...clone(site), reachable: ... }))`), and there are more sites in 1.1. Three callers in both builds (index.html lines 9463, 9527 and 30772 now), so the count of calls is not new; AG-162 names a 10 Hz poll of this runtime among 1.1's DOM work. About 8 kB a frame averaged; not isolated further.
3. **`updateZombies` (index.html; CU-173's finding for the stages):** +11 kB a frame (+5 %), the zombies' own code and what it calls.
4. **Three's own `updateNumber`, `needsRefresh`/`equals`, `getDynamicCacheKey`:** about +17 kB a frame together, proportional to the number of render objects it walks: 1.1 has more draws (CU-174: 269 against 290, higher in 4 of 4 pairs) from the new world's dressing, the FOB and the HQ stations. No single owner.

Together 1 to 4 account for about +60 of the +70 to +90 kB a frame. It is 8 to 10 % more garbage, not a new kind: no spike overlaps a collection and the collections are the same count in both builds, so it does not by itself explain the spikes; I name it because it is the one measurable thing 1.1 does more of.
