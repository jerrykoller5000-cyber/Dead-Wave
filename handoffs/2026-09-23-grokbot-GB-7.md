## Root cause

Probe before the fix (marine next to a floored pillar, eye-height side ray):

- `dy=0 .. -0.2` -> **null** (terrain closer than the post; limit blocked the shaft)
- steeper down -> pillar; top-down -> floor (decks cover the cap)

So a real player aiming flat/side at a low pillar often hit grass first. The harness
comment that swapped to `placeBuildAt(..., { piece })` was papering over that.

## Fix (build aim only)

1. **`pickHitT`**: fatter aim box for `pillar` / `ptop` (0.55 m) so the visible post/cap
   registers.
2. **`pickBuildOnRay`**: `pillarLimit = groundT + 2.5/L` so pillars can win a short way
   past terrain; other pieces still use the strict ground limit.
3. **Turret place modes only**: if a floor/platform and a pillar are nearly co-hit
   (corner seam), prefer the pillar so side-aim along the deck edge sticks to the post.
