# GB-111 — R3 P-120: enemy-first-seen, for GP-80's first-use cards

Changed:
- New `dw-game` event, `'enemy-first-seen'` `{ kind, day }` (plus the usual `runId` and `eventId`):
  - It fires once a run per zombie kind, the first time one of that kind comes within 60 m of the marine.
  - `kind` is the `ZOMBIE_TYPES` key (shambler, feral, brute, demon, screamer, …).
  - It never fires twice for a kind in one run, whether another one of that kind comes closer or the first one stays near.
  - The cave guardian of the scripted grab never counts. A new run (`uiRunId`) starts the list again.
- What the player notices: nothing by itself. ChatGPT's first-use cards (GP-80) can now pop the first time each new enemy shows up.
- Co-op: today there is one marine. P-120 says `nearestPlayer` (D-58), which comes with Cursor's CU-63 and doesn't exist yet. When it lands, the one distance check in `noteFirstSeen` should switch to it.
