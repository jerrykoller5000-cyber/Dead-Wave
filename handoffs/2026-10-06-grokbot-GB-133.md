## (1) The launcher's brass
- The drum reloads shell by shell. completeReloadStep reset `launcherEjectDone` before each next shell, and `launcherReloadSpent` (the brass to throw) never went down. So each shell reopened the eject block and threw all the brass again.
- After a 1-shot reload there was 1 case, so that case looked right. After 3 fired: 3 x 3 = 9 cases. After 6: 36. That is Jerry's "six for every one".
- Now `launcherSpent` counts the fired cases still in the drum: +1 a shot, capped at 6. The eject block throws them once, then sets it (and launcherReloadSpent) to 0.
- Two places used to treat empty chambers as brass, and now don't:
  - startReload no longer falls back to `6 - ammo`;
  - a shell going in no longer resets the count to `6 - ammo`.

  So an empty chamber with no case in it (a debug top-up, a new gun) throws nothing.
- TT.launcherBrassDbg() returns { thrown, spent } for tests.
