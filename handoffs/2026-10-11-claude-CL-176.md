# CL-176 · Claude · Half walk and run pace while shouldered

Jerry: "Lets slow the players walk and run speed by half when in aim mode."

## What changed (index.html only)

- `OTS_SLOW = 0.5` next to the other OTS knobs.
- The ground target speed is multiplied by `(1 - OTS_SLOW * OTS.w)`, so walk, run and crouch are all halved while the shoulder aim is fully in, and the pace eases back with the camera (about a second) when he lets go. The sniper scope, swimming and the ladder are untouched (the shoulder aim is off there).

## Checked (cloud, headless, SwiftShader, a match)

- Walk 6.62 m/s -> 3.35 m/s with the shoulder aim fully in (0.51).
- Run 10.82 m/s -> 5.75 m/s (0.53; the small gap is the ground slope along a different heading).
- No page errors. Main script passes node --check.
- Rebased onto the newest index.html before saving.
