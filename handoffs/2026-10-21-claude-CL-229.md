# CL-229: equal shaders are equal text (three's buffer names)

**What AG-107 run 1 showed (CL-227 in):** night 20 High 56.5 fps, 1 % low 36.3 (from 25.7), the demon fists' 18
shadow pipelines gone. But 19 zombie-skin pipelines were still built, each with a new vertex shader, although every
skeleton is now 32 bones (t270 4/4 on the 5080). So the bone count was not the reason.

**The reason:** three r175's WGSL builder names an unnamed buffer uniform after its node's id:
`uniformNode.name = name ? name : 'NodeBuffer_' + uniformNode.id` (vendor/three/three.webgpu.js, WGSLNodeBuilder
getUniformFromNode). A skinned body's bone matrices and an InstancedMesh's instance matrices (under 1,000 instances)
are such buffers. A body with its own material builds its own node graph, so its buffer gets a new id and the
shader text differs by that one name: a new program and pipeline the first frame it's drawn. Every new zombie mesh
did it, and so did every per-zombie InstancedMesh (the demon's fists, the screamer's vapour) and any InstancedMesh
made mid-run.

**Changed (index.html, after the renderer comes up):** on the WebGPU backend, the builder's `getUniformFromNode`
is wrapped: an unnamed buffer, storage buffer or indirect storage buffer gets the name `dwBuf<n>`, n the order the
builder meets it, kept per node, so within one shader each buffer has its own name and equal shaders come out as
equal text. `?bufnames=0` turns it off for measuring. The GLSL (WebGL2 fallback) builder ignores the name, so nothing
changes there.

**Tests (cloud, headless Chromium, WebGPU on SwiftShader):** `qa/2026-10-21-CL-229/pipe-probe.html`, three
r175 alone. Three InstancedMeshes sharing a material: 3 vertex programs before, 1 with the wrapper. Two instanced
meshes and two skinned meshes with their own materials and skeletons, drawn to a render target and read back: every
quad is in its place and colour, the same with and without the wrapper (programs 3 before, 2 after).
**Not verified:** the whole game on WebGPU. In the cloud it doesn't boot within 10 minutes on SwiftShader with or
without the wrapper; the real check is AG-108 on the 5080 (the bench, the pipelines journal, and a look).
