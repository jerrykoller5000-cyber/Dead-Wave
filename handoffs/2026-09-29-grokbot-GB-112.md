# GB-112 - The guardian can catch him again after an escape; each escape takes more presses (R2, P-32)

Changed: `kickFreeUsed` (one escape a run) is now `kickFreeCount` (escapes so far this run). Every guardian haul (the scene or the old drag; the walk-in snatch and the pit still never) can be kicked free. The presses rise with each escape: 5 for the first, then 8, then 12, then 16, and 16 from then on (`KICK_FREE_STEPS`). The count is fixed when the catch starts (`sk.kickNeed`). The cost is GB-78's every time: 50 HP (never below 1) and the unbanked skulls. A new run starts back at 5. The 'cave-guardian' escape events carry the right `need`, so GP-53's "Kick free! (E)" coach reads 0/8, 0/12 and so on. From the second escape on, the receipt is 'kick-free:<run>:<day>:<n>', so the UI shows "It took your skulls" again for a second escape on the same day; the first receipt is unchanged. 'guardian-kick-free' also carries `escapes` (the run's count). What the player notices: getting caught again after an escape is no longer certain death. He can fight his way out again, but it's harder each time (the prompt asks for more presses), and it still costs him half his health and his bag.
