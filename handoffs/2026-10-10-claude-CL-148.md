# CL-148: Jerry's zombie takes play from z-sounds/, folder by folder (Claude, 2026-10-10)

Jerry (on Claude's list of next jobs): get the game ready for his ElevenLabs zombie sounds, so a take dropped in a
folder is heard without waiting on anyone.

**How it works for Jerry:** drop takes (mp3/wav/ogg, any names) into their folder under `z-sounds/` (CL-145 made the
112 folders, each with its `_prompt.txt`). The next start of the game plays them; walking into the Training Ground
looks again, so takes added while the game runs are heard there. A folder with no takes keeps the game's own sound.
`Listen to Z-Sounds.bat` opens `z-sounds/listen.html`: every folder, its prompt, how many takes, each take, and one
"as in the game". His Z-Sounds layout (`04 - New Voices\Bomber\Hit Reaction`, `Cave Guardian\Idle`,
`Leaper\Movement`, `Colossus\Footstep`) is understood too, so that folder can be copied in whole. Loudness by ear:
`z-sounds/levels.json` (`{ "zombies/brute": 1.3, "footsteps/shuffle": 0.6 }`, longest folder wins).

## Files
- `core/takes.js` (new): the folder list (112, as z-sounds/manifest.json), `takeFolderFor(path)` (both layouts),
  `groupTakes`, `levelFor`, and `createTakeBank` (list, decode to mono, even each take to one loudness per kind,
  pick without repeating, per-zombie pitch 0.92-1.08, top rolled off with distance, 28 at once, `refresh()`).
  shambler/feral/footsteps/impacts/horde/build-attacks decode as soon as the list arrives; other folders the first
  time they're asked for (that once the synth plays). `core/takes.test.mjs`: 5 pass.
- `core/audio.js` (Cursor's file; ChatGPT's voice routing untouched): `playTake(id, v, pan, when, emitter, rev)` and
  one line at the top of each sound, which returns early when a take played:
  playZombieCry (every voice state, the leaper's move, demon charge, colossus step), zombieHit (flesh-hit / heavy),
  headshot, gore (small / big), zombieDeath's body fall, deadStep (shuffle, barefoot feral+leaper, waterlogged,
  boots, hop, crawl), heavyStep (heavy / huge), emerge, groan (groan-near), distantGroan (distant), scream
  (screamer call), spit and acidHit (spider), bossRoar and bossSlam (guardian), guardianGrowl, caveScreech,
  caveGroan, guardianInWalls (cave guardian), buildHit and buildBreak (wood, stone, sand, wire, metal/steel,
  turret). The list loads at unlock(). API: `AudioSys.take`, `takesInit`, `takesRefresh`, `takesState`,
  `takesPreload`.
- index.html: `bomberBlast` plays `zombies/bomber/burst` over the grenade blast; `enterTraining` calls
  `AudioSys.takesRefresh()`.
- `tools/serve.py` and `tools/serve.mjs` (Cursor's): `GET /__zsounds` lists the audio under z-sounds/ (JSON,
  relative paths). `tools/zsounds-index.mjs` (new) writes `z-sounds/index.json` for anything else that serves the
  game (the game reads /__zsounds, then index.json). serve.py also names .wav/.mp3/.ogg types.
- `z-sounds/listen.html`, `z-sounds/README.md` (how to), `Listen to Z-Sounds.bat` (new; starts serve.py if needed).
