Tips

Movement

  • WASD / arrows — move
  • Shift — run
  • Space — jump
  • Mouse — aim · RMB — zoom

Combat

  • LMB — fire / hold chainsaw
  • G — grenade · F — knife
  • R — reload

Weapons

  • Scroll / Q / E — cycle weapons
  • Minigun, M4, Pistol, Uzi, Shotgun, Revolver, Sniper, Launcher, Chainsaw

Build

  • B — enter / exit build mode
  • Scroll or 1–6: barricade · wall · spikes · light · flame · heavy
  • LMB place · Esc exit build
  • T — repair nearby build · X — sell for scrap
  • Earn cash from kills and supply drops — waves attack from the bearings shown on the map

Misc
