# Even more sounds for ElevenLabs (CL-161, batch 3)

84 prompts: the roof crew, the crew's burial, the story (the relay, the tone, the Marrow), the new death screen, and the gaps batch 2 left. Each prompt gives four takes, in the folder named under it inside `z-sounds/`. Same settings as before: Sound Effects, Duration as shown, Prompt influence about 0.6, Loop only where it says LOOP.

- **NEW** (25): for things that aren't built yet (the roof crew, their rescues and the burial, the new MISSING IN ACTION screen). Nothing plays them until those are built.
- **MISSING** (27): the game makes no sound there now.
- **UPGRADE** (26): the game makes it from synthesis now; a recording should be better.
- **TRY** (6): gunfire. Record, compare, keep whichever is better.

**Start with the ★ ones** (20).

When the takes are in, tell Claude: each one goes in the way batch 2's did (a folder with no takes keeps the game's own sound).
