# Weapon sounds, before and after (CL-134)

Open `index.html` in this folder (double-click it): each gun and each handling sound has a grey "before" and a gold
"after" button. Or play `weapon-sounds-reel.mp3`: every gun before, then after, back to back.

Everything was recorded straight out of the game's audio engine (core/audio.js), at the default volume, so the levels
here are the levels in the game.
